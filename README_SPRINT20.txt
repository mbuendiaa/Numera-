NUMERA SPRINT 20 - USUARIOS POR EMPRESA Y ARRANQUE CON DOBLE CLIC

1. Ejecuta INSTALAR_UNA_VEZ.bat solo la primera vez.
2. Después abre START_NUMERA.vbs para arrancar backend, frontend y navegador sin ventanas CMD visibles.
3. Para cerrar Numera ejecuta STOP_NUMERA.bat.

GESTION DE USUARIOS
- El primer usuario que crea la empresa queda como propietario.
- Desde Configuracion > Usuarios, propietario o administrador crea la cuenta completa.
- El nuevo usuario queda vinculado automaticamente a la empresa activa.
- No necesita registrarse, crear empresa ni seleccionarla manualmente.
- Si la cuenta ya existia, se vincula a la empresa sin duplicarla.
